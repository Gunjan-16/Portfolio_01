# Personal Portfolio

This is my personal portfolio website where I have added a little about myself, my skills, projects, and contact information.

I built this website while practising HTML, CSS and JavaScript.

## Live Website

[Visit my portfolio](https://portfolioo-taupe-one.vercel.app/)

## About the Website

The portfolio has separate pages for:

- Home
- About
- Skills
- Projects
- Contact

The home page gives a quick introduction, while the other pages contain more details about my skills and projects.
